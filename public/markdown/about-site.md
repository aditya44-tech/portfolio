# About This Site

This site is inspired by macOS 26 Tahoe with modern Liquid Glass design, developed using [React](https://reactjs.org/), [Zustand](https://zustand-demo.pmnd.rs/), [Framer Motion](https://www.framer.com/motion/), and [UnoCSS](https://uno.antfu.me/).

The source code is hosted on GitHub: [aditya44-tech/portfolio](https://github.com/aditya44-tech/portfolio).
