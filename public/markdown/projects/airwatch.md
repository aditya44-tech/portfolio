# AirWatch — Real-Time AQI Dashboard for India

Live air-quality monitoring and analytics for Indian cities, in one clean
dark-mode interface.

- **Interactive pollution map** — AQI markers across major cities
- **48-hour history + 24-hour predictions** — rush-hour and weather aware
- **City comparison** — pollutant levels side by side
- **AI insights** — Gemini analyzes uploaded CSV datasets into advisories
- **Health recommendations** — personalized guidance per AQI level

**Tech:** Next.js 15, React Leaflet, Gemini API, Recharts, Tailwind, Vercel.

**Repo:** https://github.com/aditya44-tech/AirWatch
