# CivicConnect — Citizen Issue Reporting

A modern platform for citizens to report local issues and track their
resolution end to end.

- **Issue reporting** — citizens file local issues with photos and location
- **Resolution tracking** — follow each report from filed to resolved
- **Roles** — citizen and admin flows with credential auth
- **Maps + uploads** — Leaflet/OpenStreetMap and Cloudinary image hosting

**Tech:** Next.js 15, TypeScript, Tailwind v4, Postgres (Neon), Prisma,
NextAuth.js, Cloudinary.

**Repo:** https://github.com/aditya44-tech/CivicConnect
