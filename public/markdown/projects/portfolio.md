# macOS 26 Tahoe Portfolio

This very site — a complete macOS Tahoe desktop recreated on the web, from the
transparent menu bar and magnification dock to 20+ working apps.

- **Desktop OS shell** — windowing, Spotlight, Launchpad, Control Center,
  Notification Center, login and boot screens
- **Real apps** — Steam game library with live achievement data, Spotify
  player, Crunchyroll anime shelf, video editor, terminal, VS Code and more
- **Themable** — Default Tahoe, Souls ember and Soul Reaper atmospheres with
  matching wallpapers, accents and cursors
- **System Settings** — appearance, wallpapers, dock and menubar preferences
  that actually work and persist

**Tech:** React, Zustand, UnoCSS, TypeScript, Vite, Framer Motion.
