# ADITYA44 — Editing Portfolio

**Live:** https://editing-portfolio-blue.vercel.app/

A high-performance dark-mode portfolio for cinematic edits, motion graphics
and commercial work.

- **3D cylinder carousel** — drag-to-spin hero with cover art per project
- **Video hover previews** — Cloudinary clips autoplay silently on card hover
- **Project lightbox** — two-column modal with player, description and metrics
- **Category filtering** — motion graphics, flow, personal edits, promos, ads
- **Skill orbit + Intel FAQ** — interactive neon skill nodes, proximity Q&A
- **Book An Edit** — inquiry form wired to email via Web3Forms

**Tech:** React, Vite, Cloudinary, Web3Forms.

**Repo:** https://github.com/aditya44-tech/Editing-Portfolio
