# LeetCode Tracker — Chrome Extension

A lightweight Chrome extension (currently in beta) that automatically tracks
LeetCode solve time and difficulty breakdown — and shows which companies ask
which questions.

- **Automatic tracking** — solve time and difficulty logged as you practice
- **Company dataset** — question-to-company mapping for targeted prep
- **Toolbar dashboard** — progress at a glance, pinnable to the toolbar
- **Manual install** — load unpacked via developer mode from Releases

**Tech:** JavaScript, Chrome Extensions API.

**Repo:** https://github.com/aditya44-tech/leetcode-tracker-extension
